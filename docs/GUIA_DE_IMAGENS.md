# Guia de imagens

O projeto usa uma estratégia híbrida:

1. Imagens locais em SVG para garantir funcionamento offline.
2. Algumas imagens de referência da Wikimedia Commons são carregadas pela internet quando houver conexão e possuem fallback local quando não houver.

Fontes consultadas para o protótipo:
- Coffee plantation in Brazil — Wikimedia Commons — domínio público: https://commons.wikimedia.org/wiki/File:Coffee_plantation_in_Brazil.jpg
- Brazilian coffee beans — Wikimedia Commons — CC BY-SA 4.0: https://commons.wikimedia.org/wiki/File:Brazilian_coffee_beans.jpg
- Coffee roasting — Wikimedia Commons — licença indicada na página: https://commons.wikimedia.org/wiki/File:Coffee_roasting.jpg

Antes de publicação comercial, revisar licença/atribuição e substituir imagens demonstrativas por fotos próprias ou imagens licenciadas para uso comercial. As embalagens SVG são criações originais do protótipo.
