LGPD

Política de Privacidade

Documento fictício para demonstração. O projeto segue princípios de minimização, finalidade e segurança: coleta apenas dados necessários para conta, entrega e histórico de pedidos.

Dados tratados

Nome, e-mail, telefone, endereços e dados operacionais de pedidos. Senhas são armazenadas somente como hash bcrypt. O checkout de demonstração não armazena CVV nem número completo de cartão.

Finalidade

Executar pedidos, autenticar clientes, manter histórico, operar fidelidade e registrar avisos de reposição.

Produção

Uma operação real deve definir base legal, prazos de retenção, encarregado/canal de privacidade, processos de direitos dos titulares e contratos com operadores.
